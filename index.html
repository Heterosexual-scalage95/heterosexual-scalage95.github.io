📖 About the software

Biovision-omics helps researchers study biological images and spatial transcriptomics. The software uses machine learning to identify patterns in your data. It supports quality control, image segmentation, and phenotype classification. You can use this tool to interpret complex biological data without manual processing.

💻 System requirements

Before you install the software, ensure your computer meets these requirements:

  • Windows 10 or Windows 11.
  • At least 16 GB of RAM.
  • A modern processor (Intel Core i5 or AMD Ryzen 5 or better).
  • A dedicated graphics card with at least 6 GB of video memory.
  • At least 50 GB of free space on your hard drive.

📥 Getting started

Follow these steps to set up the software on your computer:

  1. Visit the official GitHub releases page to download the software installer.
  2. Locate the downloaded file in your downloads folder.
  3. Double-click the installer file.
  4. Follow the on-screen prompts to complete the installation process.
  5. Once finished, launch the application from your desktop or start menu.

⚙️ How to use the application

The application interface consists of a dashboard for data management and an analysis tab for processing images. Start by importing your raw image files into the designated data folder. The system logs the progress of your analysis automatically.

To begin an analysis, select the specific imaging files from the navigation window. Choose the segmentation task if you want to identify individual cells. Use the transcriptomic interpretation tool to map gene activity to your visible data. The software saves all output files into a folder labeled "results" for your review.

🛠️ Troubleshooting

If you encounter errors, check these common items:

  • Ensure your graphics drivers are up to date.
  • Verify that your firewall allows the application to access the network.
  • Check that your file paths do not contain special characters.
  • Restart your computer if the application becomes unresponsive.

📁 Data management

The software handles large datasets by processing one file at a time. This keeps your machine stable. You should store your research data on a fast solid-state drive to ensure quick access. Always keep a backup of your inputs in a separate folder.
